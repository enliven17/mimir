# Third-party brand assets

Logos belonging to other companies are not vendored into this repository. Each
one is that company's trademark, carries its own usage rules, and an
approximation drawn by hand is worse than no logo at all.

Drop the official file in and the UI picks it up automatically. Until then the
components fall back to a plain-text wordmark, so the attribution is correct
either way.

| File | Where to get it | Used by |
| --- | --- | --- |
| `coinmarketcap.svg` | CoinMarketCap brand assets | `components/brand/CoinMarketCapMark.tsx`, shown on the landing page's settlement-data section and on price claims |

Keep the file in its original form. Do not recolour, stretch or redraw it; the
components size it by height and leave the aspect ratio alone.
